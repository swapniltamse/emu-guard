How this page and emu-guard were built

The page

  • It is one static HTML file with its own CSS. There is no framework and no build step.
  • It has no tracking, no analytics and no cookies. The only outside request loads the fonts from Fontshare.
  • The small script on the page adds the copy buttons. Everything else works without it.
  • Headings use Clash Grotesk and body text uses Sentient. Icons come from Tabler Icons.
  • The share image is drawn from HTML and saved as a PNG.

The support table

  • The scores come from the per-test scores file that AWS published with AWS Emulator v1.0.341, scores.json.gz.
  • Only the behavioral fidelity tests count, as the AWS docs describe them.
  • AWS does not publish control plane and data plane scores separately. They come from joining each test result to its plane label in the public test manifest.
  • The full method and every service are in the fidelity snapshot.

The tool

  • emu-guard is one PowerShell script, one bash script, two Dockerfiles and a test.
  • It does not change AWS Emulator. It starts the emulator and checks each run before your command starts.
  • It was tested on Windows 11 with Docker Desktop. The bash script is not yet run on macOS or Linux.
